# Super Niu Niu 練習卓

マニラのカジノで遊ばれている **Super Niu Niu（超級牛牛）** を、スマホで練習するための非公式アプリです。リアルマネーは一切使いません。

**▶ 遊ぶ：** https://OWNER.github.io/super-niu-niu/

## できること

| タブ | 内容 |
|---|---|
| 入門 | 11ステップのチュートリアル。手を組む・精算するを実際にやりながら覚える |
| 卓 | サイコロで配り始めが決まるディーラー卓。EVEN / DOUBLE / SUPER をベットし、自分で3枚＋2枚に組む |
| 役作り | 5枚から10の倍数の3枚を探す反復ドリル（正答率・平均秒数を記録） |
| 精算 | 勝ち負け・タックス・ニウ6半額を含む精算額の4択ドリル |
| ルール | 配当表、同点の決め方、控除率、卓設定（CoD型 / Solaire型） |

成績と資金はブラウザ内（localStorage）にだけ保存されます。ホーム画面に追加するとアプリのように使え、一度開いた後はオフライン（機内など）でも動きます。

## ルールの出典

配当は City of Dreams Manila の公式ガイドを標準にしています。カジノごとに細部が異なるため、実際の卓では卓上の配当表を必ず確認してください。

- [City of Dreams Manila · Super Niu Niu Rules and Guidelines](https://www.cityofdreamsmanila.com/sites/g/files/cityofdreamsmanila/files/2022-01/TableGames_GamingGuide_Super%20Niu%20Niu.pdf)
- [Solaire · Niu Niu](https://sec.solaireresort.com/gaming/solaire-niu-niu)
- [Hoiana · Niu Niu](https://www.hoiana.com/table-games/hoiana-niu-niu)
- [Okada Manila · Super Niu Niu Plus](https://okadamanila.com/casino-game/super-niu-niu-plus/)

各カジノとは無関係の個人制作物です。フィリピンのカジノは21歳以上のみ入場可。遊ぶときは余裕資金の範囲で。
